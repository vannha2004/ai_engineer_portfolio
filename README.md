# AI & ML Systems Engineer Portfolio

Interactive portfolio showcasing low-latency Large Language Model (LLM) serving, enterprise Retrieval-Augmented Generation (RAG) engines, autonomous multi-agent reasoning graphs, and deep learning systems.

## Features
- **Interactive LLM VRAM & Inference Sizer**: Real-time calculation of model weights, KV-cache sizing with GQA (Grouped-Query Attention), and hardware recommendations (RTX 4090, A100, H100).
- **Multi-Stage RAG Simulator**: Visualizing the dense embedding, sparse BM25, and cross-encoder reranking stages with grounded zero-hallucination outputs.
- **Multi-Agent DAG Trace Viewer**: Inspecting stateful agent execution with internal ReAct thought traces and sandboxed tool calls.
- **Production Architecture Showcase**: Real projects spanning vLLM serving clusters, multi-agent code security auditors, and multimodal vision diagnostics.
- **Skills Matrix & Research Publications**: Breakdown of deep learning frameworks, MLOps tooling, and technical publications.
- **Interactive CLI Inspector**: In-browser terminal emulator for quick diagnostics (`help`, `about`, `skills`, `metrics`, `contact`).
